# --- Local embeddings (Chapter 3). Swapped from the spec's suggested `sentence-transformers`
# (all-MiniLM-L6-v2) to spaCy's en_core_web_md: sentence-transformers downloads its model
# weights from huggingface.co at runtime, and this repo's build environment's egress policy
# blocks every huggingface.co/hf.co host outright (confirmed, not a transient error — see
# PROGRESS.md's Unit 4 notes). spaCy's model ships as a single self-contained wheel hosted on
# a GitHub release, so `pip install -r requirements.txt` alone installs real, offline-capable
# word/document vectors (300-dim, GloVe-based) with no separate download step for anyone,
# regardless of their network's access to Hugging Face.

en-core-web-md @ https://github.com/explosion/spacy-models/releases/download/en_core_web_md-3.8.0/en_core_web_md-3.8.0-py3-none-any.whl
